# Day 3 – Summary: Error Handling, OOP, Outlook

## Topics of the Day

- **Errors and exceptions**: Syntax errors vs runtime errors, try/except, targeted error handling
- **OOP basics**: Defining classes, creating instances, instance and class attributes, properties
- **Inheritance**: Subclasses, super(), multiple inheritance
- **Outlook**: NumPy, SciPy, Matplotlib - brief introduction and applications

## Important Concepts

- Catch exceptions with try/except; optionally else and finally.
- Define classes with `class ...:`; self as first argument of instance methods.
- Inheritance: `class Child(Parent):`; super() for calls in the parent class.
- NumPy for arrays and numerical computation; Matplotlib for plotting.
