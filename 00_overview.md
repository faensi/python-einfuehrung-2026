# Python Basics - Course Overview

## Welcome

This course is for **scientists and researchers with no prior Python experience**. In three days you will learn the fundamentals of programming with Python: data types, control structures, input/output, modules, error handling, object-oriented concepts, and an outlook on important libraries and tools.

---

### Day 1: Python Basics and Data Structures
**4 Notebooks (00-03)**

- **Python Overview**: What is Python, differences from other programming languages
- **Data Types, Variables, Objects**: Basic concepts of types, classes, variables, and objects
- **Strings**: Character strings and important string functions
- **Dictionaries and Sets**: Dictionaries, sets, and frozensets as built-in data structures


---

### Day 2: Control Structures, Input/Output, and Modules
**5 Notebooks (04-08)**

- **Conditions**: Branching with `if`/`else`
- **Loops**: `while` and `for` loops, `continue`, `break`, `else` with loops
- **Functions**: Defining and calling functions
- **Input and Output**: Interactive input, formatted output, `format()`, reading and writing files
- **Modules and Libraries**: Using the standard library, installing external packages with pip


---

### Day 3: Error Handling, OOP, and Outlook
**4 Notebooks (09-12)**

- **Errors and Exceptions**: Understanding syntax errors, handling exceptions with try/except
- **OOP Basics**: Classes, instances, instance and class attributes, properties
- **Inheritance**: Simple and multiple inheritance
- **Outlook**: Brief introduction to NumPy, SciPy, and Matplotlib

**What you will learn**: You will handle errors effectively and understand the fundamentals of object-oriented programming in Python, as well as applications of important libraries.

---

### Day 4: Logging, Lambdas, NumPy, Pandas, APIs, Tools, and TIFF
**7 Notebooks (13-19)**

- **Logging**: Basic logging setup and levels
- **Lambda Functions**: Anonymous functions, sorted/filter/map
- **NumPy**: Why arrays are better than lists for calculations
- **Pandas and Matplotlib**: Tabular data (CSV/JSON), visualization
- **Using APIs**: HTTP requests, JSONPlaceholder example
- **Python Tools Overview**: Conda, Mamba, Anaconda/Miniconda, conda-forge, PyCharm, Jupyter, common terms (theory only)
- **TIFF**: Working with TIFF images (tifffile, at3_1m4_01.tif)

---

## Course Learning Objectives

By the end of the course you will be able to:

- Work with Python efficiently
- Apply fundamental programming techniques with confidence
- Classify application areas of Python
- Be familiar with important Python libraries
