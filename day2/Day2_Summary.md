# Day 2 – Summary: Control Structures, I/O, Modules

## Topics of the Day

- **Conditions**: if/elif/else, Boolean expressions
- **Loops**: while, for, range(), continue, break, else with loops
- **Functions**: def, parameters, return values, calling
- **Input and output**: input(), print(), format(), reading and writing files with open()
- **Modules**: import, standard library, pip and external packages

## Important Concepts

- Blocks are defined by indentation; no braces.
- for loops iterate over sequences (e.g. range, lists, strings).
- Functions can have default arguments and multiple return values.
- Open files with `with open(...) as f:`, then read/write.
- Use `pip install <package>` for external libraries.
